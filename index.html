O projekcie

Strona zostala zbudowana z trzech plikow: index.html, style.css oraz script.js. Dzieki rozdzieleniu struktury, stylow i logiki latwiej pokazac, jak Git sledzi zmiany w poszczegolnych plikach i jak wygladaja diffy.

Podstawowe komendy Gita

  1. git init - utworzenie nowego repozytorium
  2. git status - sprawdzenie stanu plikow
  3. git add . - dodanie zmian do poczekalni
  4. git commit -m "opis" - zapisanie commita
  5. git log - przegladanie historii
  6. git push - wyslanie zmian na zdalne repozytorium
